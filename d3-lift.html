Lift3D

A projection in reverse: a flat table of rows and columns is lifted into 3D space, then projected back onto your screen with a draggable camera.

Drag to rotate · scroll or pinch to zoom · hover a point to see its row.

Using the library

const scene = Lift3D.create(svgElement, rows, {
  mode: 'axes',            // 'axes' | 'pca' | 'grid'
  x: 'horsepower', y: 'weight', z: 'mpg',
  color: 'origin', size: 'price',
  projection: 'perspective' // or 'orthographic'
});
scene.update({ mode: 'pca' });          // change anything, re-lifts and redraws

// Or use the pure functions without rendering:
const lifted = Lift3D.lift(rows, { mode: 'pca' });   // points in [-1, 1]³
const flat   = Lift3D.project(lifted.points[0].pos,
                 { yaw: -.7, pitch: .5, scale: 190, cx: 400, cy: 280 });
